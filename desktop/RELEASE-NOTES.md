Unsigned Windows x64 installer for the existing local AI Video setup.

- StudioAI > Manual updates shows the installed version and opens GitHub Releases.
- Save edits, finish/cancel queued work, and quit StudioAI before installing over the previous version. Do not uninstall first.
- The installer refuses to proceed while StudioAI is running.
- Models, Python environments, media, captions and workspace data stay in the selected external runtime folder.
- No automatic update downloads or installations. No signing subscription required.
- Keep Windows security enabled. If Windows blocks the unsigned installer, stop rather than changing security or trust settings.

SHA256SUMS.txt provides the download checksum, not publisher authentication. This build requires your existing local runtime and is not a fresh-PC AI/model installer.
